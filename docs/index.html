Optional API key

The crime section uses the FBI's free API. The shared DEMO_KEY is rate-limited, so if crime data doesn't load, get a free key at api.data.gov. It's saved only in this browser and sent only to the FBI API.

Adding homes from listing sites

  • Android: open this site in Chrome, tap ⋮ → Add to Home screen (or Install app). After that, PA Home Scout appears in the Share menu of the Zillow, Redfin and Realtor.com apps and of Chrome – share a listing to it and it's added here.
  • Computer: drag this button to your bookmarks bar: + PA Home Scout. Then click the bookmark while viewing any listing.
  • iPhone / iPad: Apple doesn't let websites appear in the Share menu. In the listing app tap Share → Copy Link (or Copy), then paste it into the box above.
  • Your list is saved in this browser only. Use Copy list link to move it to another device.
Data: Zillow ZHVI, US Census ACS & Gazetteer, NCES / Urban Institute Education Data, FBI Crime Data Explorer, OpenStreetMap, FEMA. Listing, amenity and service links go to Zillow, Redfin, Realtor.com, Google Maps, Yelp and BBB. Figures are estimates for the ZIP code area, not a specific property.
