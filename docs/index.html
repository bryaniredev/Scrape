PA Home Scout

Enter a Pennsylvania ZIP code to research home prices, listings, schools, safety and amenities.

Optional API keys

Keys are saved only in this browser (localStorage) and sent only to the service they belong to. Every section works or degrades gracefully without them.

Get keys: RentCast · api.data.gov · Census

Data: Zillow ZHVI, US Census ACS, RentCast, OSRM, NCES / Urban Institute Education Data, FBI Crime Data Explorer, OpenStreetMap, FEMA. Figures are estimates for the ZIP code area, not a specific property.
