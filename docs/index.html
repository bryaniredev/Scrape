Adding homes from listing sites

  • Android: open this site in Chrome, tap ⋮ → Add to Home screen (or Install app). After that, PA Home Scout appears in the Share menu of the Zillow, Redfin and Realtor.com apps and of Chrome – share a listing to it and it's added here.
  • Computer: drag this button to your bookmarks bar: + PA Home Scout. Then click the bookmark while viewing any listing.
  • iPhone / iPad: use the options below in Safari (not a home-screen copy of this site – that keeps a separate list). Quickest without any setup: in the listing tap Share → Copy, come back here and tap Paste & add.
  • Your list is saved in this browser only. Use Copy list link to move it to another device.
iPhone: add “Add to PA Home Scout” to the Share menu (one-time, ~2 minutes)
  1. Open the Shortcuts app and tap + to make a new shortcut.
  2. Tap Add Action, search for Expand URL and add it. It should read Expand Shortcut Input (tap the blue placeholder and pick Shortcut Input if not). This turns the apps' short links into full listing links that contain the address.
  3. Add a second action, Open URLs. Tap its blue URL placeholder and paste this:
    then, straight after it, tap Expanded URL in the bar above the keyboard (or Select Variable → Expanded URL) so the link ends with the Expanded URL bubble.
  4. Tap the ⓘ / settings button and turn on Show in Share Sheet. At the top, make it receive URLs, Safari web pages and Text.
  5. Name it Add to PA Home Scout and tap Done.

Already made the shortcut? Edit it: add Expand URL (of Shortcut Input) at the top, then in Open URLs replace the Shortcut Input bubble with Expanded URL.

Now, in Safari or the Zillow / Redfin / Realtor.com apps, tap Share on a listing and choose Add to PA Home Scout. Safari opens this page with the home added. (If it isn't listed, scroll to the bottom of the Share menu → Edit Actions and add it.)
